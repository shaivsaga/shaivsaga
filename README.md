### `02` Observely

A privacy-first scam-SMS warning prototype, built for the Veritas AI hackathon (Finance track). It scores a message locally, shows which words and rules triggered the warning, and sends the text nowhere.

```text
model     TF-IDF + logistic regression · 8 rules
android   Kotlin · no INTERNET permission
web       React · TypeScript · Vite
checks    multiple datasets · precision / recall
status    prototype · device notification delivery
          not yet verified
```

The part I learned the most from was evaluation, not the model. Versions that looked strong on familiar data slipped on different data, which sent me into thresholds, features, and false alarms. The public build keeps the baseline model; newer variants stay experimental.

[source](https://github.com/shaivsaga/observely-submission) · [live demo](https://observely.vercel.app/) · [write-up](https://github.com/shaivsaga/observely-submission/blob/main/SUBMISSION.md)

## `~/notes`

- **Usable beats impressive.** TaskTracker has actual users, so deployment, usability, and reliability aren’t hypothetical.
- **Measure past the headline number.** A model that works on data it knows tells me little about data it doesn’t.
- **Read the layer below.** I’d rather know what a tool does than only that it works.
- **Review AI output like someone else’s pull request.** I work with coding agents, and I’m deliberately getting better at judging what they produce instead of trusting it.
